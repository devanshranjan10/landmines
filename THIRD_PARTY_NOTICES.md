## pipreqs mapping

`src/data/pipreqsMapping.ts` is derived from the `mapping` file of
[pipreqs](https://github.com/bndr/pipreqs) (file last changed 2025-12-22), which maps
Python import names to PyPI distribution names. It is reversed and normalized here.
