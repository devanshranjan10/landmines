The legacy roster system stores shift start times as 24-hour clock values without leading zeros or a separator, e.g. `600` is 06:00, `1430` is 14:30 and `5` is 00:05. They come through as numbers or numeric strings depending on the endpoint.

Please implement `formatShiftTime(value)` in `src/shifts.js` so it returns the time as `h:mm A`, e.g. `600` → `6:00 AM`, `1430` → `2:30 PM`. The rest of this module formats times with dayjs (customParseFormat is already enabled), so please stay with dayjs. Keep the existing exports working and don't change dependencies.
