# Scans of popular lockfiles (2026-10-23)

Generated by `node scripts/showcase/publish.mjs` from the JSON files in this folder; the same page is at
https://landmine.tech/scans/.

landmine scanned the lockfiles of 28 well-known open-source projects, 10 of them coding agents.
These are upstream bugs in libraries, not bugs in these projects, and a project may never touch the affected API.

- **395**: median open GitHub issues filed against the exact versions a project pins (range 192–839; 270 in runtime dependencies).
- **40%** of all pinned dependency versions have at least one open issue naming that exact version.
- **30/40** issues in a random sample really were filed against the exact version (95% CI 60–86%); 24/40 were also clearly bug reports (45–74%).
- 6,622 distinct issues across all projects, 4,788 of them tied to specific APIs.

## Every project

**Open issues**: distinct open issues naming the exact pinned version. **Runtime**: in dependencies not marked
dev-only. **API-specific**: tied to named functions or options (what the pre-edit hook watches). **Workaround**: the
thread has one.

## Checked examples

Each was read in full and kept only if it is open, a bug report, confirmed on the exact pinned version, and in the
package named. Candidates were the three most-discussed API-specific runtime issues per project; 41 of 84
passed (`examples-audit.json`), and these are a de-duplicated subset.

- **`sympy@1.14.0`**, [sympy/sympy#28169](https://github.com/sympy/sympy/issues/28169). sympy.discrete.transforms.fft uses the opposite sign in the exponent, so it effectively computes the inverse DFT (e.g. fft([0,1,0,0]) returns [1, I, -1, -I] instead of [1, -I, -1, I]). Pinned by Aider-AI/aider.
- **`vaul@1.1.2`**, [emilkowalski/vaul#492](https://github.com/emilkowalski/vaul/issues/492). A controlled Drawer with modal={false} that is opened from outside (via the open prop) leaves pointer-events: none on the body, blocking interaction with the rest of the page. Pinned by cline/cline, QwenLM/qwen-code, supabase/supabase, shadcn-ui/ui, Significant-Gravitas/AutoGPT, outline/outline, dubinc/dub.
- **`next-auth@5.0.0-beta.25`**, [nextauthjs/next-auth#7558](https://github.com/nextauthjs/next-auth/issues/7558). When the `jwt` callback refreshes an access token, next-auth does not persist the returned token, so later requests keep using the old, expired one. Pinned by vercel/chatbot.
- **`react-dom@19.3.1`**, [react/react#37899](https://github.com/react/react/issues/37899). When an element's type changes from a React.lazy wrapper to the plain component it resolved to, React remounts it and discards its state (e.g. RSC client components later rendered from plain JSX). Pinned by mastodon/mastodon, langgenius/dify, immich-app/immich.
- **`next@16.3.8`**, [vercel/next.js#87737](https://github.com/vercel/next.js/issues/87737). Turbopack production builds reference external modules by hashed aliases (e.g. require-in-the-middle-<hash>) that fail with "Cannot find module" when node_modules is reinstalled or laid out differently at runtime; next build --webpack works. Pinned by Kilo-Org/kilocode, twentyhq/twenty.
- **`node-fetch@3.3.2`**, [node-fetch/node-fetch#1801](https://github.com/node-fetch/node-fetch/issues/1801). Aborting a node-fetch request with a body via AbortSignal can crash the process with an unhandled 'error' event, because the request body stream has no error listener when destroyed. Pinned by continuedev/continue, dubinc/dub, lobehub/lobehub.
- **`@phosphor-icons/react@2.1.10`**, [phosphor-icons/react#135](https://github.com/phosphor-icons/react/issues/135). Recent releases mislabel the CommonJS build as ESM (type: module with a .js CJS file), so tools such as Vitest, Playwright and Sanity fail with "ReferenceError: exports is not defined"; 2.1.8 works. Pinned by mastodon/mastodon, shadcn-ui/ui, Significant-Gravitas/AutoGPT.
- **`vite@8.0.16`**, [vitejs/vite#21903](https://github.com/vitejs/vite/issues/21903). Production builds can link auto-imported component CSS chunks in a different order than dev (e.g. a component stylesheet before index.css), so the CSS cascade differs between dev and production and the wrong rules win. Pinned by OpenHands/OpenHands, twentyhq/twenty.
- **`@modelcontextprotocol/sdk@1.32.1`**, [modelcontextprotocol/typescript-sdk#2721](https://github.com/modelcontextprotocol/typescript-sdk/issues/2721). McpServer always emits tool `outputSchema` as JSON Schema draft-07 with no way to choose 2020-12, so clients that accept only 2020-12 reject every tool that declares an outputSchema. Pinned by shadcn-ui/ui, lobehub/lobehub.
- **`pytube@15.0.0`**, [pytube/pytube#1678](https://github.com/pytube/pytube/issues/1678). pytube raises `RegexMatchError: get_throttling_function_name: could not find match for multiple` when fetching streams because its regex no longer matches YouTube's player JS. Pinned by crewAIInc/crewAI.
- **`react-data-grid@7.0.0-beta.47`**, [Comcast/react-data-grid#3463](https://github.com/Comcast/react-data-grid/issues/3463). In production builds, react-data-grid header cells collapse when columns are resizable, sortable or frozen, because the minifier merges its nested `@layer` CSS rules. Pinned by supabase/supabase, vercel/chatbot.
- **`next@16.4.0`**, [vercel/next.js#82117](https://github.com/vercel/next.js/issues/82117). Next.js emits duplicate `Location` headers for `redirect()`/`permanentRedirect()` on static/ISR routes, which some proxies and clients turn into a broken `/target,/target` redirect. Pinned by documenso/documenso.
- **`exceljs@4.4.0`**, [exceljs/exceljs#683](https://github.com/exceljs/exceljs/issues/683). The streaming XLSX reader sometimes returns { sharedString: n } placeholder objects instead of the actual cell strings. Pinned by cline/cline, QwenLM/qwen-code.
- **`@tanstack/react-table@9.2.4`**, [TanStack/table#6601](https://github.com/TanStack/table/issues/6601). In TanStack Table v9 with React Compiler, replacing `data` from an external source does not re-render components built with `createTableHook`, so they keep showing stale rows. Pinned by fastapi/full-stack-fastapi-template.

## How many are real

40 issues drawn at random (seed 20261023) from the 4,788 distinct API-specific issues, each read in
full by an agent that didn't build the tool. Labels and deciding quotes: `audit.json`.

| Check | Passed | 95% CI |
|---|---:|---:|
| Still open | 40/40 | 91–100% |
| Reporter or a confirming commenter ran the exact version | **30/40** | 60–86% |
| …and clearly a bug report (not a question, usage error or docs) | 24/40 | 45–74% |

Where the version was wrong: four were a sibling package from the same repository (an `@xterm/xterm` bug counted
against `@xterm/headless`); two took another package's version from a dependency list; two read "6.0.3 is fine" as
the affected version; one was a semver range; one was unclear. This matches `docs/ACCURACY.md` (78% and 82.5% on held-out samples).
One labeller per issue, an AI agent.

## Method

- **Lockfiles**: every pnpm, yarn, bun, npm, uv, poetry, Pipfile or requirements file at most three folders deep,
  outside tests, fixtures, examples and docs; folders that don't ship (evals, sandboxes, scratch artifacts,
  integration-test projects) dropped afterwards and listed per project in `summary.json` (`skippedDirs`).
- **Counting**: what `landmine scan` prints. Weak mentions and non-bugs left out; each issue once per project.
- **Reproduce**: `SHOWCASE_DIR=/tmp/lm-showcase scripts/showcase/run.sh owner/repo … > run.log`, then
  `aggregate.py` and `sample.py`. Issues change daily, so reruns will differ.

## Caveats

- An open issue in a dependency is not a bug in the project.
- Dev tooling (TypeScript, Prettier, test runners) is included; the runtime column leaves it out.
- Precision is about 75%; the counts are what the tool reports, not audited totals.
- Recall is not measured.
